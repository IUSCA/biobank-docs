# API Reference

The {{PLATFORM_NAME}} API is a REST API. It offers the portal's functions over HTTPS.

The full reference is at [{{WEBSITE_URL}}api/doc/]({{WEBSITE_URL}}api/doc/).

## Access keys and where they work

A script signs in to the API with an access key, which you make on your **Profile** page. See [Access keys](/guide/getting-started.md#access-keys). Each key's scopes limit what it can do.

{{TRE_PORTAL_ACCESS_NOTE}}

Listing and downloading a cohort's data files work only from inside a workspace in the trusted research environment. Other operations, such as searching cohorts, work from anywhere with a key.

For the command-line client, see the [API Client guide](/guide/api-client.md).
